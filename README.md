# LuckySort

A procedural robotic manipulation benchmark for Lucky Engine: a robot arm sorts
randomly generated colored objects into one stack per color, largest at the bottom.
Tasks are generated from a seed, executed with Lucky's robot control and MuJoCo
physics, and judged by an independent evaluator that inspects the physical result.
